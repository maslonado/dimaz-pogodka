# dimaz-pogodka
погода в туле
Weather Tula — Open Meteo Weather UI

Современный погодный интерфейс на чистом HTML/CSS/JavaScript с использованием Open-Meteo API

============================================================================
Возможности

🌤 LIVE прогноз погоды
📅 Прогноз на 7 дней
🌡 Температурные графики
💨 Скорость ветра
🚀 Без библиотек и фреймворков
🔑 API без ключа

============================================================================

🌍 API

Проект использует:

https://open-meteo.com/

============================================================================

Установка:

установить файл 3.html из официального репозитория, открыть его в браузере.

============================================================================

📱 Responsive

Интерфейс адаптирован для:

Desktop
Tablet
Mobile

============================================================================

🌙 Dark/Light mode
📍 Геолокация пользователя
🛰 Погода по GPS
🌦 Почасовой прогноз
📈 Recharts / Canvas графики
🌍 Выбор города
